# 0.4.0 已知问题与验证范围

这次公开保留当前运行时代码、Papyrus 源码、数据构建器和配置，没有实施后续讨论中的修复。下面是已经确认的具体问题，不代表完整审计结果。

## 惊惧的范围恐惧遗漏

私人集成产物中，三个 Dismay 私有根法术均为 Self，实际 `EFIT.area` 为 0。仅 `MGEF.SpellmakingArea` 为 50/75/100，没有补齐实际范围施放所需的效果区域或载体。不能把 0.4.0 描述为已经完成 FT 的范围恐惧机制；公共成长将零区域乘倍率也不能补齐它。

## True Cone 视觉和碰撞未使用统一几何变换

当前默认视觉基础倍率 `V = 1 + 0.03S`，高度补偿 `H = 40(V - 1)`。根节点还乘随距离计算的锥角修正，部分核心节点额外缩放，Soul Tear 不使用该核心节点变换。高度只取基础倍率，沿根节点 Z 位置加偏移，没有按共同视觉/碰撞中心推导。

锥形碰撞将初始半径乘 `1 + 0.05S`，锥角至少 15°。代码使用的截面关系是初始半径与距离项相加，不能把它描述为整个锥形在所有距离都统一放大同样倍数。视觉与碰撞的公式因此不保证中心或外缘严格重合。

统一倍率、共同中心/锚点和旋转感知补偿是后续讨论方向，**尚未实施**；本次公开没有将 VFX 改为 `1 + 0.05S`。
