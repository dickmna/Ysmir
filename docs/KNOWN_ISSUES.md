# 0.8.0 验证范围与边界

完成 Release 原生编译、数据生成、六个 Papyrus 脚本编译、65 项离线场景、ESP/稳定 ID/0.5 功能清单比较、Steam 1.7.104.0 PE/RTTI/钩子元数据核对和安装包完整性校验。360 条玩法记录与 0.7.0 完全相同，仅 TES4 说明改版；原生元素、成长、碰撞和视觉模块保持。详见 BUILD-REPORT.json。没有启动游戏、部署模组或修改加载顺序。

回归覆盖每目标独立开始/完成、1/2/3 次脚本控制流、随机间隔、新进入目标、敌友变化、死亡、距离、室内外、原版天气调用、v3/v4/v5 存档记录以及引用清理；同时回归成长、锥形开关、九条元素规则和延迟快照。C++ 使用引擎服务替身，PEX 检查执行实际编译指令并模拟 native/时间，不模拟完整 Skyrim VM。

- 尚待游戏实测：RemoteCast 在该运行时的真实发射/命中、抗性/吸收与归责、雷击可见性和音画同步、天气交接，以及高龙魂/多敌人时性能。不能称作所有功能完美。
- 连击中的 Papyrus 栈和 SKSE 目标记录需要在真实存读档中联合验证。离线记录往返与暂停位置检查不能证明游戏 VM 保存/恢复执行栈正常。
- Utility.Wait 受 Papyrus 负载影响；随机间隔是请求的等待时间，不是精确的帧级保证。延迟唤醒不集中补发后续雷击。
- 死亡、转友、出范围或结束会取消尚未发射的雷击；已发射投射物仍按引擎正常运行。目标数不加人为上限，每个有效目标两枚复用定位物、最多一个活跃连击栈。
- 原有普通 ScriptEffect/CloakEffect 快照与元素冷却读档后重建；风暴保留独立存档记录。共享视觉材质只能同时显示一组浓度；NIF 动画与碰撞不保证完全重合。
- 仅核验 Steam 1.7.104.0 / SKSE64 2.3.1；外部 Address Library 文件本次未重新核验，其他运行时不在本次范围。
