# 0.9.1 验证范围与边界

完成 Release 原生编译、两次确定性数据生成、96 项离线场景、Steam 1.7.104.0 PE/RTTI/钩子元数据核对和安装包逐文件校验。360 条玩法记录与 0.9.0 的载荷、标志及 FormID 完全相同，仅 TES4 说明改版；六个 PSC/PEX、18 NIF、4 DDS 保持原字节。详见 BUILD-REPORT.json。没有启动游戏、部署模组或修改加载顺序。

31 组视觉场景覆盖出生、统一变换下的层间尺寸/间距、嵌套节点和装饰节点、移动锚点及旋转父节点、原生动画顺序、不重复累乘、浓度/材质更换、开关、非锥形与风暴显示路径。测试运行生产模块，场景图与引擎服务为替身；它不模拟真实渲染、粒子、Havok、VM 或天气。

- 整体缩放仍会扩大纹理花纹、波纹厚度和模型自带的位置偏移；没有 UV 平铺、新网格或新粒子。它保留组合关系，不等于可见边界精确贴合碰撞。出生平滑接入可能偏小，原版模型已有的视觉/判定偏差不会被自动修复。
- 尚待游戏实测：远端覆盖、层间衔接、地面穿插、浓度/亮度、雷击显示、抗性/吸收与归责、天气交接及高龙魂/多敌人性能。不能称为所有功能完美或已优于 TCSF。
- 保留原有浓度共享基线；不同投射物若共享材质，只能同时显示一组浓度。模型替换、特殊根节点动画与其他视觉插件共同运行仍需验证。INI 在初始化时读取，修改后应退出并重启游戏。
- 风暴仍是每目标独立随机 RemoteCast 1/2/3 次。Utility.Wait 会受 VM 负载影响，不保证帧级精确间隔；死亡、转友、出范围或结束取消尚未发射的雷击，已发射的投射物按引擎运行。
- Papyrus 连击栈与 SKSE 目标记录需要真实存读档联合验证。普通效果快照与元素冷却仍在加载后重建；没有新增序列化版本。
- 仅核验 Steam 1.7.104.0 / SKSE64 2.3.1；外部 Address Library 文件本次未重新核验，其他运行时不在本次范围。
