# 0.5.0 验证范围

0.4.0 的惊惧 EFIT 范围遗漏已补为 50/75/100；原版恐惧等级与持续时间保留。视觉已统一默认倍率、中心锚点和距离计算；旧校准分支、额外核心节点放大和经验抬高已移除。

本次完成 DLL、数据构建器和五个 Papyrus 脚本编译，以及 ESP 引用/数值、PE 元数据、实际游戏程序与 Address Library 地址核对。没有启动游戏、修改游戏目录或加载顺序，也未验证游戏内帧率、命中表现、脚本时序或旧存档迁移。

几何公式遵循原始视觉与碰撞匹配的假设，不能据此宣称所有 NIF 粒子外缘像素级吻合；见 [几何与实例状态](ARCHITECTURE.md)。脚本/cloak 的瞬时快照不跨读档序列化，读档后按加载基线重建。共享材质只能显示一组外观值，来自不同实例的浓度差异仍受底层共享关系约束，不影响各实例的碰撞或数值快照。

只支持 Steam 1.7.104.0。新增的投射物 Launch 入口要求匹配已核验的入口字节；若其他 DLL 先改写这个入口，本插件会拒绝加载并记录原因。未声明其他 Steam、GOG、VR 版本兼容。

公开源码不含第三方输入和私人集成运行包；现在可以使用官方文件和五个原始上游插件重新生成数据，不再依赖历史 Ysmir ESP。
