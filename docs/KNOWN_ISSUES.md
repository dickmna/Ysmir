# 0.9.0 验证范围与边界

完成 Release 原生编译、两次确定性数据生成、101 项离线场景、Steam 1.7.104.0 PE/RTTI/钩子元数据核对和安装包逐文件校验。360 条玩法记录与 0.8.0 的载荷、标志及 FormID 完全相同，仅 TES4 说明改版；六个 PSC/PEX、18 NIF、4 DDS 保持原字节。详见 BUILD-REPORT.json。没有启动游戏、部署模组或修改加载顺序。

九份原版模型的节点与材质已检查；分层增长、UV 独立副本、动画前恢复/动画后应用和通用锚点通过离线测试。真实可见边缘与命中范围没有做画面对照，不能声称已优于 TCSF。分层增长仍使用网格缩放，不会生成新几何；平铺补偿只改善纹理细度，不能保证波纹厚度、折射、接缝或边缘完全对应判定。出生接入阶段可能偏小；其他模型继续使用通用根节点缩放。

回归覆盖每目标独立开始/完成、1/2/3 次脚本控制流、随机间隔、新进入目标、敌友变化、死亡、距离、室内外、原版天气调用、v3/v4/v5 存档记录以及引用清理；同时回归成长、锥形开关、原生半径/切线只读、smoothstep、锚点与材质状态、九条元素规则和延迟快照。C++ 使用引擎服务替身，PEX 检查执行实际编译指令并模拟 native/时间，不模拟完整 Skyrim VM。

- 尚待游戏实测：RemoteCast 在该运行时的真实发射/命中、抗性/吸收与归责、雷击可见性和音画同步、天气交接，以及高龙魂/多敌人时性能。不能称作所有功能完美。
- 连击中的 Papyrus 栈和 SKSE 目标记录需要在真实存读档中联合验证。离线记录往返与暂停位置检查不能证明游戏 VM 保存/恢复执行栈正常。
- Utility.Wait 受 Papyrus 负载影响；随机间隔是请求的等待时间，不是精确的帧级保证。延迟唤醒不集中补发后续雷击。
- 死亡、转友、出范围或结束会取消尚未发射的雷击；已发射投射物仍按引擎正常运行。目标数不加人为上限，每个有效目标两枚复用定位物、最多一个活跃连击栈。
- 原有普通 ScriptEffect/CloakEffect 快照与元素冷却读档后重建；风暴保留独立存档记录。通用路径的共享材质仍只能显示一组浓度；分层路径只对独占 property 创建可变材质，遇到共享 property 或不兼容材质时跳过 UV 补偿。NIF 动画与碰撞不保证完全重合。
- 仅核验 Steam 1.7.104.0 / SKSE64 2.3.1；外部 Address Library 文件本次未重新核验，其他运行时不在本次范围。
