# 0.7.0 验证范围与边界

完成 Release 原生编译、数据生成、五个 Papyrus 脚本编译、52 项实际代码/函数体的替身回归、ESP 记录与旧版清单比较、Steam 1.7.104.0 PE/RTTI/挂钩元数据核对以及安装包完整性验证。完整结果见 BUILD-REPORT.json。没有启动游戏、部署模组或修改加载顺序。

回归覆盖九条元素触发计时、重吼、重叠词阶、菜单；风暴全目标重扫、敌友变化、死亡、距离、错峰、卡顿、室内外、原版天气施放/结束、v3/v4 记录读取及开关；成长公式、原生施法调用参数、锥形开关、安全碰撞和延迟快照。替身不实现 Skyrim 的物理、Papyrus VM 或实际抗性结算。

仍需游戏内验证雷抗/吸收目标的最终伤害、无赏金归责与其他 perk 组合、天气交接、Slow Time/Dragon Aspect 脚本时序、旧存档完整迁移、高龙魂命中与帧率，以及其他 DLL 的组合。离线通过不能称作所有功能完美。

- 普通 ScriptEffect/CloakEffect 快照不跨读档序列化，加载后按加载基线重建；风暴单独保留自己的记录迁移。
- 元素狂暴冷却不因重吼清零，但读档/新游戏重建其瞬时计时与快照；未宣称整个 DAC 的跨会话状态完全等同。
- 共享材质只能显示一组浓度；原 NIF 动画与碰撞包络不保证视觉上完全重合。
- “对所有敌人打击”指每批向所有合格目标施放真实雷击；是否造成伤害由游戏的命中、抗性、吸收等机制决定。
- 仅核验 Steam 1.7.104.0 / SKSE64 2.3.1；未重新检验外部 Address Library 文件，其他 Steam/GOG/VR 版本不在范围内。
- 风暴更接近原版施法链，原生特效边界修复仍保留；不恢复独立的全目标引雷 Papyrus 扫描器。

旧 0.6.0 文档将风暴笼统归为“SCSO v3”、将 Soul Tear 15° 说成上游原值、把三个元素冷却当作完整上游规则，均由本版纠正。第三方资源和许可未改变；本地交付不代表公开再发布。
