# Ysmir 0.7.0 功能与重构说明

已按“原版机制优先、保留 0.5.0 功能、只移除投射角度加宽”的目标完成本地重构、编译和离线验证。安装包、匹配源码和验证记录一并交付。未启动游戏，也未部署或远程发布。

## 实际改动

| 部分 | 0.7.0 实现 |
| --- | --- |
| 风暴伤害 | 删除手动扣血，使用真实原版雷击法术，基础 40/60/80，保留 ResistShock。引擎 MagicCaster 生成法术 power、效果与归责；小钩子只调整空中起点/方向/目标。 |
| 风暴目标与批次 | 保留动态敌我识别，按一/二/三词对所有合格敌人发起一/二/三批雷击，每批重新搜索和复查。错峰与原有范围/节奏配置继续保留。 |
| 天气与持续 | 原版 magicSetWeatherScript 和 Update 的例外表负责天气；引擎效果管理时长。室内攻击暂停但时长继续，外出不积压补击；旧 v3 风暴记录可读取。 |
| 元素狂暴 | 按元素×词阶保留九条独立 50%/2 秒规则，重吼不清计时；重叠词阶分别检查，菜单时间计入冷却。 |
| Soul Tear | 仅把固化的 15° 改回上游 10°；锥形命中、官方伤害和复活参数保持，不导入额外复活增强。 |
| 桥接和快照 | 仅六个实际桥接 MGEF 与 cloak 跟踪父效果；将快照和取消状态合并。保留旧实例倍率及必要的四个效果脚本和 native 声明脚本。 |
| 完整性补回 | 恢复 0.6.0 连带删除的 True Cone 总开关、碰撞开关、视觉开关及 GetDragonSoulCount 接口。只删除角度补偿选项。 |

SCSO Pure SKSE Beta 本身只给已有雷击补击，不提供动态寻敌。为满足本次明确要求，Ysmir 保留了一个小型全目标调度器；不再将它描述成“SCSO 原样移植”。所有主击和补击使用真实游戏法术，是否造成伤害交给游戏的命中、抗性和吸收等机制。

不能直接用普通 Cast 替换所有桥接：Papyrus 延迟执行时需要知道父效果当初的倍率。删掉这个联系会破坏“重吼后旧实例不变”的 0.5.0 行为。保留这层小桥接，比再加全局拦截和推测施法来源更直接。

## 验证结果

- 原生 DLL Release x64 编译通过；数据构建通过；五个 Papyrus 脚本编译零错误、零警告。
- **52 项替身逻辑回归通过**：17 项桥接/碰撞/开关结果、17 组风暴场景、9 组元素触发、9 组成长与原生施法参数场景。
- 0.5.0 的 **350 条记录及其 ID 全保留**，78 个根词位数值清单不变；最终 360 条记录，无未解析引用。
- 与 0.6.0 实际 ESP 逐记录比较：**348 条旧记录载荷完全相同**；仅 Soul Tear、风暴两条投射物变更，另加 10 条风暴 Spell/MGEF。
- 原版天气脚本及全部属性与官方获胜记录一致；风暴实际 MGEF 保留 Health/DualValueModifier/ResistShock；未增加私有成本 perk。
- ESP 与 RuntimeForms.h 在冻结 ID 后重复生成逐字节一致。DLL 版本、导出、实际 1.7.104.0 EXE 的入口/虚表检查通过；外部 Address Library 文件未重新校验。
- 两个 ZIP 通过 CRC 与逐文件 SHA-256 校验；运行包为 1 DLL、1 ESP、1 INI、5 PEX、18 NIF、4 DDS，加源码和说明。
- 项目七个 C++ 文件由 2066 行减至 1467 行，其中风暴由 942 行减至 297 行，包含注释/空行。这是代码体积变化，不是性能测试结论。

## 安装与尚待实测

使用新完整包替换旧 Ysmir 模组目录，并以本版 INI 为基础迁入自定义值。直接沿用旧 INI，会保留其中的旧风暴伤害覆盖。对应环境是 Steam 1.7.104.0、SKSE64 2.3.1 和匹配 Address Library；源码包用于重编译，不能当运行包安装。

这些证据确认了代码、记录、调用参数和逻辑分支，**不能保证游戏内所有功能完美**。尚待实测：雷抗/吸收与归责的最终效果、旧存档真实加载、天气交接、Slow Time/Dragon Aspect 脚本时序，以及高龙魂命中和帧率。普通脚本/cloak 快照与元素冷却仍在读档时重建；风暴单独迁移其保存记录。共享材质只能显示一组浓度，原始 NIF 动画不保证与碰撞完全重合。

机器记录见 `Ysmir-0.7.0-验证结果.json`，包哈希见 `Ysmir-0.7.0-SHA256.json`。之前交付的 0.6.0 ZIP 和说明保持原样。
