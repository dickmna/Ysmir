# Ysmir 0.9.1：整体缩放精简测试版

按用户确认的方案，将所有锥形 VFX 统一为围绕原始锚点的整体缩放。删除 0.9.0 的分层与专用 UV 处理，保留原版出生大小、龙魂距离成长、原始角度和初始碰撞半径；不抬高、不更换投射 NIF。

## 回退与源码

修改前已将 0.9.0 提交 733c0c82c51834f1e6aa123b4f0b90417edaf476 同步到 GitHub 的 backup/ysmir-0.9.0 和 v0.9.0，并核验远端。0.9.0 的完整包、源码包、说明和验证报告保留原文件。0.9.1 源码分支为 codex/ysmir-uniform-visuals。

## 实现

- 删除模型白名单、节点名前缀识别、分层状态、纹理名识别、UV scale 写入和独立材质副本；没有新增框架、脚本、定时器或存档记录。
- 根节点统一放大，内部节点 local 变换不再被额外修改。原模型的波面、烟雾、拖尾及附属几何共同变化，避免各层尺寸变大而层间间距保持不变。
- 出生附加倍率为 1。沿用 0.9.0 距离公式 Q=(r+d*t)/(r+(d/K)*t)，V=1+(Q-1)*smoothstep(clamp(d/256,0,1))。K 为该次龙魂距离倍率，r/t 只读原生锥形参数；零龙魂无附加放大，没有固定四倍或四倍上限。
- 保留原锚点及原生 3D 更新顺序：更新前撤回上帧根节点补偿，原生动画更新后应用当前倍率。补偿根节点平移以稳定锚点，不另加高度。
- 保留既有浓度补偿：普通透明度与加法材质强度、Cyclone/BendWill 排除、共享基线与材质替换跟踪。纹理 UV 和材质对象不再作专门改动。

## 其他功能与验证

Release DLL 编译通过；两次数据构建的 ESP、RuntimeForms.h 和 FormIds.json 相同。与 0.9.0 相比，360 条玩法记录的载荷和标志完全一致，仅插件头版本说明变化。六份 PSC/PEX、18 个 NIF、4 张 DDS 与旧包逐字节相同；没有加入新的投射模型。

96 项离线场景通过：17 项桥接/开关、20 项风暴、9 项元素触发、11 项成长/发射、31 项完整视觉模块、8 项实际风暴 PEX 控制流。新增对组合内几何点、层间距离、嵌套与附属节点应用同一变换的检查；保留出生、锚点、动画、不重复累乘、浓度、非锥形及风暴边界检查。

风暴每目标独立随机 RemoteCast 1/2/3 次、动态敌我识别及新敌人加入、失效停止、原版天气/伤害/抗性，元素狂暴九条规则，Soul Tear 10°，Slow Time 玩家豁免，FT Dragon Aspect/英灵/库存模型，动态推力和其他成长均保留。对应实现文件与玩法记录核对未改变。

只读核验最终 DLL 与本机 Steam 1.7.104.0 的版本、导出及钩子元数据；没有重新核验外部 Address Library 文件。离线场景使用引擎替身，不能证明真实渲染、VM、碰撞边界或存档恢复正确。整体缩放仍会放大花纹和波纹厚度，不能声称已优于实测有效的 TCSF。

## 安装与游戏测试

目标运行时：Steam Skyrim 1.7.104.0 / SKSE64 2.3.1 / 匹配 Address Library。用完整包替换旧 Ysmir，Data 作为数据目录，启用 Ysmir.esp；源码包不能当运行包。保留升级前存档，不同时启用重复的独立控制器。

先测三词不卸之力：零龙魂和 100 龙魂、每魂 5%，比较出生大小、近中远端覆盖、波面/烟雾/拖尾衔接及锚点高度，再测火焰、寒霜各词阶和 Soul Tear。之后确认风暴、元素狂暴和 Slow Time。

默认 DensityCompensation=1。设 0 只关闭浓度补偿；PatchVisuals=0 只关闭锥形视觉补偿，距离成长仍保留。fVisualTransitionDistance=256 控制平滑接入距离。NativeWaveGrowth 已删除，旧配置中残留该键也不会启用分层。配置修改后重启游戏。

General.bDebugLogging=1 可在 SKSE/Ysmir.log 看到 uniform root scale、浓度目标数与距离倍率。需要回退时恢复 0.9.0 完整包及升级前存档。本次未部署到游戏或更改加载顺序。
