# Ysmir 0.4.0 私人集成产物的当前行为

这份说明描述已构建的私人集成产物；公开仓库只发布源码与配置，未附完整安装包。已确认遗漏以 [KNOWN_ISSUES.md](KNOWN_ISSUES.md) 为准。

按最终功能范围重构：以 Shout Progression 的施放事件与倍率快照思路构建一个公共核心，接入 True Cone、动态冷酷之力、SCSO 和选定的龙吼机制。运行包包含一个 DLL、一个 ESP、一个 INI 和五个轻量 Papyrus 桥接脚本。

保留 FT 库存模型与火龙灵的敌对筛选/移动行为修复。黑书能力和帕图纳克斯冥想沿用官方玩法，不引入 FT 的额外玩法、等级系统、Phantom Form、任务或词墙修改。

## 公共成长

26 条玩家龙吼、78 个词位使用生成的私有记录映射。所有私有龙吼图归类为 `MagicShout`，取消五大学派归属。关键词驱散效果保留其筛选列表，必要时用无脚本的分类效果标记，防止误驱散其他龙吼。战斗狂怒按用户的明确排除要求保持不动。

默认 `S` 为未消费龙魂：幅度、距离、范围、持续时间和碰撞倍率均为 `1 + 0.05S`；冷却为 `0.95^S`。慢时间保持上述固定持续时间。VFX 为 `V = 1 + 0.60 × 0.05S`，True Cone 高度增加 `120 × (V-1)/3`，浓度为 `1 + 1.2 × (V-1)/3`。True Cone 将低于 15° 的锥角提高到 15°，已有更大角度不缩小，无额外玩法上限。

一次施放读取一次龙魂，并让核心与适配器共享同一快照。数据加载时缓存原始数值及法术关联，后续从基线计算，不在每次施放递归发现记录。NPC、龙和米拉克不使用这些玩家私有增强。

## 安装与替换

需要 Steam Skyrim **1.7.104.0**、[SKSE64 2.3.1](https://skse.silverlock.org/)、[Address Library v13 / All in One 1.7.104](https://www.nexusmods.com/skyrimspecialedition/mods/32444?tab=files)、游戏自带官方 masters 和 Visual C++ x64 Runtime。地址库文件为 `Data/SKSE/Plugins/versionlib-1-7-104-0.bin`。本包不捆绑 SKSE 或地址库，不声明其他 Steam、GOG、VR 版本兼容。

用模组管理器安装集成包，将包内 `Data/` 设为数据目录，并启用 `Ysmir.esp`。升级时完整替换旧 Ysmir 模组目录，避免留下已经移除的脚本和 Phantom Form 资源。源码包用于构建，不要作为运行模组安装。

关闭被整合的独立控制器和对应 ESP/兼容补丁：Shout Progression、FT、True Cone、Dynamic Unrelenting Force、SCSO、93681、62686、49359 的相应组件。包内已接入的逻辑再次加载会重复执行；其他未整合的动画/外观模组按各自需求处理。FT 旧全局脚本只在它们确实来自旧 Ysmir/FT 安装时随所属模组一起撤下。

0.4.0 删除了旧版任务和大量私有记录，不能承诺带有旧 FT/Phantom Form 活动实例的旧存档无损迁移。保留原存档，优先用独立存档验证。本次没有部署到游戏或修改加载顺序。
