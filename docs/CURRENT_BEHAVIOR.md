# Ysmir 0.9.0 集成产物的当前行为

这份说明描述已构建的私人集成产物；公开仓库只发布源码与配置，未附完整安装包。验证范围以 [KNOWN_ISSUES.md](KNOWN_ISSUES.md) 为准。

按最终功能范围重构：以 Shout Progression 的施放事件与倍率快照思路构建一个公共核心，接入 True Cone、动态冷酷之力、风暴错峰增强和选定的龙吼机制。运行包包含一个 DLL、一个 ESP、一个 INI 和六个轻量 Papyrus 脚本。

保留 FT 库存模型与火龙灵的敌对筛选/移动行为修复。运行包附 FT 全部 17 个龙吼菜单模型，以及所需召唤特效和纹理；不包含 Community Shaders 专用模型修复，也不依赖社区着色器。黑书能力和帕图纳克斯冥想沿用官方玩法，不引入 FT 的额外玩法、等级系统、Phantom Form、任务或词墙修改。

## 公共成长

26 条玩家龙吼、78 个词位使用生成的私有记录映射。所有私有龙吼图归类为 `MagicShout`，取消五大学派归属。关键词驱散效果保留其筛选列表，必要时用无脚本的分类效果标记，防止误驱散其他龙吼。战斗狂怒按用户的明确排除要求保持不动。

默认 `S` 为未消费龙魂：幅度、距离、范围、持续时间、非锥形碰撞/视觉倍率均为 `1 + 0.05S`；冷却为 `0.95^S`。Slow Time 保持上述固定持续时间。锥形起始半径和角度保持原始值，由引擎继续扩张碰撞；VFX 出生为原始大小，按原生几何和距离成长计算目标，以 smoothstep 平滑过渡。默认基础视觉参考 4 倍、前 256 单位完成过渡，保持投射物参考点的模型锚点；无额外高度偏移、子节点二次放大或 NIF 替换。浓度跟随当帧尺寸平滑变化。公式、开关与近似边界见 [架构说明](ARCHITECTURE.md#锥形和视觉)。

一次施放读取一次龙魂，并让核心与适配器共享同一快照。只有六个桥接 MGEF 与 cloak 需要父效果上下文。父效果结束或销毁后，其排队的子法术取消；禁用 General/Storm 后风暴不会恢复或继续。投射物出生后固定快照；脚本效果与 cloak 保存实例快照，命中和延迟施法临时应用对应值。读档后的效果在首次恢复更新时按该次加载的龙魂基线重新建立快照。保留 GetDragonSoulCount API。True Cone 的总开关、视觉开关和总 VFX 开关保留；锥形碰撞成长开关已删除，旧键忽略。fVFXPerSoul 仅继续影响非锥形，锥形视觉随距离成长补偿。数据加载时缓存原始数值、法术关联及效果缩放规则，后续从基线计算，不在每次施放递归发现记录。NPC、龙和米拉克不使用这些玩家私有增强。

## 风暴的独立节奏

扫描默认每 0.25 秒更新。每个新目标独立等待 3–6 秒后开始第一轮；一/二/三词分别施放 1/2/3 次，每个相邻间隔独立抽取 0.12–0.35 秒。完成后独立抽取下一轮等待：一词 3–6 秒、二词 0.75–6.75 秒、三词 0.25–5.25 秒。INI 数值和旧键名保留，fPassStagger 现在表示同一目标的相邻雷击间隔。

每次施放前复查敌友、存活和范围，实际发射钩子再检查一次。新敌人不等待其他目标；死亡、转友、离开范围或风暴结束后停止剩余施放。室内暂停攻击但风暴时长继续；返回室外不集中补发。Papyrus 的实际等待可能受负载影响，这些时间不是硬实时保证。

v5 风暴存档保留本次成长和各目标身份/下一轮节奏，旧 v3/v4 继续读取；连击中的次数与 Wait 依赖原生 Papyrus 栈恢复。离线已验证记录往返与编译脚本控制流，真实存档恢复尚待实测。

## 安装与替换

需要 Steam Skyrim **1.7.104.0**、[SKSE64 2.3.1](https://skse.silverlock.org/)、[Address Library v13 / All in One 1.7.104](https://www.nexusmods.com/skyrimspecialedition/mods/32444?tab=files)、游戏自带官方 masters 和 Visual C++ x64 Runtime。地址库文件为 `Data/SKSE/Plugins/versionlib-1-7-104-0.bin`。本包不捆绑 SKSE 或地址库，不声明其他 Steam、GOG、VR 版本兼容。

用模组管理器安装集成包，将包内 `Data/` 设为数据目录，并启用 `Ysmir.esp`。升级时完整替换旧 Ysmir 模组目录，避免留下已经移除的脚本和 Phantom Form 资源。源码包用于构建，不要作为运行模组安装。

关闭被整合的独立控制器和对应 ESP/兼容补丁：Shout Progression、FT、True Cone、Dynamic Unrelenting Force、SCSO、93681、62686、49359 的相应组件。包内已接入的逻辑再次加载会重复执行；其他未整合的动画/外观模组按各自需求处理。FT 旧全局脚本只在它们确实来自旧 Ysmir/FT 安装时随所属模组一起撤下。

0.4.0 曾删除旧版任务和大量私有记录，不能承诺带有旧 FT/Phantom Form 活动实例的旧存档无损迁移。保留原存档，优先用独立存档验证。0.5.0 合并了一个重复库存模型记录；0.7.0 保留 0.5.0 的全部 350 条记录 ID 和 78 个词位数值清单，另加 10 条原版风暴法术/天气记录。旧 STRM v3 风暴记录读取已做逻辑回归；完整旧存档加载仍未做游戏内验证。0.9.0 与 0.8.0 的 360 条玩法记录及标志逐项一致，仅插件头说明改版本；六个 PSC/PEX 和全部 NIF/DDS 均逐字节保留。重构前 GitHub v0.8.0 和本地 0.8.0 安装包均保留；可靠回退应恢复对应旧包和升级前存档。本次没有部署到游戏或修改加载顺序。
