# Ysmir 0.9.2：按传播进度平滑放大

本版将锥形 VFX 的倍率统一到龙魂距离成长。整体缩放、原版出生大小与锚点、浓度补偿和其他玩法沿用 0.9.1；不抬高、不换投射 NIF。

## 公式与行为

K 为该次施放保存的龙魂距离倍率，默认 K=1+龙魂数×0.05。读取投射体已经传播的距离 d 和实例射程 L，计算：

```text
p = clamp(d / L, 0, 1)
V = 1 + (K - 1) * p*p*(3 - 2*p)
```

L 是引擎已经记录的成长后射程，不再乘 K，也不取会被后续施放改变的共享基础记录。整段射程连续平滑；到终点达到 K，越界封顶 K。零龙魂始终 1 倍，无效距离/射程/倍率回到 1。这里的 V 是乘在该帧原版动画上的额外线性倍率。

100 龙魂、每魂 5% 时 K=6：

| 传播进度 | 额外视觉倍率 |
| --- | --- |
| 出生 | 1 |
| 25% | 1.78125 |
| 50% | 3.5 |
| 75% | 5.21875 |
| 射程末端 | 6 |

删除视觉计算中的初始半径和锥角读取，移除 fVisualTransitionDistance；旧配置中的该键忽略。没有新增调参开关、尺寸测量、逐节点逻辑或框架。与 0.9.1 的前 256 单位接入相比，新版近处增长更缓，之后按整段射程增长。提前撞击或消失时只显示到当时的倍率。

## 保留范围

projectile_visuals.cpp 保持不变：更新前恢复自己的上帧缩放，原生动画更新一次，再围绕原锚点整体缩放并应用原有浓度补偿。内部节点、UV 和 NIF 不改，无额外高度。材质跟踪、排除规则、非锥形视觉和风暴显示边界路径不变。

龙魂距离继续同时成长速度和射程；初始碰撞半径和角度保持原值。风暴每目标动态敌我筛选、随机 RemoteCast 1/2/3 次，元素狂暴、Soul Tear、Slow Time、FT、英灵/库存模型、动态推力、其他成长及快照保留原实现。

## 验证

Release DLL 编译通过。103 项离线检查通过：17 桥接/开关、20 风暴、9 元素、11 成长/发射、38 视觉、8 实际编译 PEX 控制流。视觉检查覆盖四分位倍率、终点、越界、不同射程、同时施放、变化后的龙魂不影响旧投射体、锚点/比例/浓度和无效输入。

两次数据构建的 ESP、RuntimeForms.h 和 FormIds.json 一致；360 条玩法记录与 0.9.1 的载荷和标志完全相同，仅插件头版本说明变化。六份 PSC/PEX、18 NIF、4 DDS 与旧包字节一致。核验最终 DLL 的版本和本机 Steam 1.7.104.0 钩子/导出元数据；未重新核验 Address Library 文件。

这是离线验证后的游戏测试包，没有启动游戏。整体缩放的纹理厚度、远端命中贴合、浓度、性能及存档联合恢复仍需游戏实测；不宣称已优于 TCSF。

## 回退与安装

修改前已将 0.9.1 提交 a85d55d71cbc9b4d7e8a94694d61060339258b5f 同步到 GitHub v0.9.1 / backup/ysmir-0.9.1，并核验远端。本地 0.9.1 输出全部保留。新源码继续位于 codex/ysmir-uniform-visuals 分支。

用完整包替换旧 Ysmir，以 Data 为数据目录，启用 Ysmir.esp。运行要求仍为 Steam 1.7.104.0 / SKSE64 2.3.1 / 匹配 Address Library。源码包不能用于安装；建议使用新版 INI 后迁移自己的数值。回退恢复 0.9.1 完整包及升级前存档。

先用三词不卸之力对比 0 与 100 龙魂（每魂 5%），观察出生、近中远端大小和锚点，再检查火焰、寒霜和 Soul Tear。独立 TCSF 用单独配置作参照，不与本版叠加。DensityCompensation=0 只关浓度，PatchVisuals=0 只关锥形视觉，距离成长仍保留；修改 INI 后重启游戏。本次没有部署到游戏或修改加载顺序。
