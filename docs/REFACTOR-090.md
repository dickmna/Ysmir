# Ysmir 0.9.0：原生锥形碰撞与平滑视觉成长

本次只重构锥形碰撞和视觉。先把当前 0.8.0 同步到 GitHub 的 `backup/ysmir-0.8.0` 分支与 `v0.8.0` 标签，核实均指向 `5c53dafc93fccd355d0fa892d9e16cb458cdd1d4`，然后才修改源码。本次源码分支为 `codex/ysmir-distance-visuals`。

## 实际变化

- 取消锥形初始碰撞半径成长。删除半径写入、半径快照和更新前处理；原始角度、起始半径、原生碰撞更新不变。
- 保留龙魂距离成长，默认速度和射程均乘 `K=1+0.05S`；幅度、持续、范围、冷却、推力等保持既定规则。
- VFX 出生为原模型的 1 倍，按已传播距离用 `w=u²(3−2u)` 平滑过渡。默认前 256 单位完成过渡；零龙魂时 0/128/256 单位对应 1/2.5/4 倍。
- 龙魂成长后的目标倍率为 `4×(r+d*t)/(r+(d/K)*t)`，再由上述权重从 1 倍接入。r/t 只读原生初始半径和切线，d 为实际移动距离。4 倍不是成长上限，也不再叠乘旧视觉倍率。
- 保持原有模型锚点，不额外抬高、不改单独子节点、不替换 NIF。浓度使用原有公式并跟随当帧平滑尺寸，出生浓度补偿为 1。
- 复用现有更新钩子和实例快照，没有新增控制器、脚本、定时器、存档格式或 DLL。

## 配置

```ini
[TrueCone]
fBaseVisualScale=4.0
fVisualTransitionDistance=256.0
```

这两项分别调整基础视觉参考和过渡距离，最小取 1。`Enabled`、`PatchVisuals` 或 `DragonSouls.bScaleVFX` 关闭即可停止锥形视觉补偿。将 `fBaseVisualScale` 设为 1，可只保留距离成长对应的几何补偿。

旧 `PatchRuntimeCollision` 键已删除且不再读取。`bScaleCollisionRadius/fCollisionRadiusPerSoul` 继续影响非锥形；`fVFXPerSoul` 继续控制非锥形视觉，锥形现在由距离成长决定。其他已有设置保持原值。旧 INI 未填写新键时使用上述默认值。

4 倍来自先前 TCSF 测试的参考；那个版本同时改变了其他碰撞/视觉条件，所以不能直接认定本版 4 倍也严格贴合。这里选择了很小、可调的实现，需要游戏内对照来校准。

## 保留功能及验证

风暴继续每目标独立随机错峰，SKSE 动态寻敌/识别敌友，短脚本 RemoteCast 按词阶 1/2/3 次；新进入者加入，死亡/转友/离开范围/结束取消后续施放。元素狂暴九条独立规则、Soul Tear、时间缓滞玩家豁免、FT 龙魂觉醒/英灵/库存模型、推力和其余龙魂成长均保留。

Release DLL 编译成功；两次数据构建的 ESP、RuntimeForms.h 和 FormIds.json 逐字节一致。对比 0.8.0，360 条玩法记录的载荷与标志全部一致，仅插件头版本说明改变。六个脚本的源码/PEX 和全部 18 NIF、4 DDS 与 0.8.0 相同。

89 项离线场景通过：17 项桥接/开关/原生碰撞保持、20 项风暴、9 项元素触发、11 项成长/发射、24 项视觉模块、8 项实际风暴 PEX 控制流。新增视觉测试执行实际模块，覆盖出生/中点/远端、零半径/零角度、无效值、锚点、引擎动画缩放、材质更换、重复更新不累积、非锥形与风暴路径。已核对 Steam 1.7.104.0 的 DLL 版本与钩子/RTTI 元数据；外部地址库文件本次未重验。

安装包仍含 1 DLL、1 ESP、1 INI、6 PEX、18 NIF、4 DDS，无 Community Shaders 依赖。完整包与源码包分别提供，并做 ZIP CRC 和成员 SHA-256 检查；旧 0.8.0 交付文件保留。

## 使用与边界

目标为 Steam 1.7.104.0 / SKSE64 2.3.1 与匹配的 Address Library。使用模组管理器完整替换旧 Ysmir 目录，包内 Data 作为数据目录，启用 Ysmir.esp。源码包不能当运行模组安装。避免同时启用已整合的独立控制器。

本次没有部署到游戏、启动游戏或修改加载顺序。离线检查不能验证实际粒子边缘、命中、视觉观感、帧率或真实存档恢复。原生 R(d) 描述的是移动扩张的碰撞球；视觉半径比仍是近似，根节点等比缩放也会影响模型长度。优先对冷酷之力、火焰、冰霜、Soul Tear，在 0/20/60/100 龙魂的近中远距离测试；重点看出口尺寸、覆盖与命中是否一致、远端拉长和粒子脱节。

升级前保留独立存档。回退使用完整的 0.8.0 包及升级前存档；GitHub 标签用于源码回退，不能单独恢复运行资产或保证新存档降级。
