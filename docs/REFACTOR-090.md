# Ysmir 0.9.0：原版波层扩张与纹理密度测试版

这是供游戏内对照的测试版。保留龙魂距离成长、原始角度、初始碰撞半径和视觉出生大小；不额外抬高、不替换投射 NIF，不改其他玩法。不能把离线通过等同于画面已优于 TCSF。

## 回退点

修改前已核验 GitHub backup/ysmir-0.8.0 / v0.8.0 的源码提交 5c53dafc93fccd355d0fa892d9e16cb458cdd1d4，并保留原完整安装包。动手前再次将未发布的视觉草稿备份到 backup/ysmir-before-native-vfx-20261021，提交 9397ff2b9b59054066b72cb73300c9aa9e4708fd。草稿备份不是推荐安装版本。本版源码分支为 codex/ysmir-distance-visuals。

## 本次实现

- 删除锥形起始碰撞半径成长，保留引擎自己的扩张。默认距离 K=1+0.05S，速度和射程同时成长；角度、初始半径不写入。
- 所有锥形特效从原始大小出发，额外倍率由实际传播距离对应的原生碰撞半径比决定，用前 256 单位的 smoothstep 平滑接入。零龙魂无额外视觉放大，没有固定四倍倍率或龙魂上限。
- 原版不卸之力、火焰吐息、寒霜吐息共九个模型采用分层路径：根节点和各层平移不变，只补偿主波、烟雾、拖尾的最外层节点。引擎继续播放自己的扩张、滚动和消散动画。
- 对确定可平铺的原版烟雾材质，使用独立的可变材质副本增加 UV 重复，减少额外扩张造成的粗大纹理；保留 alpha、发光和 UV 滚动。不生成新网格、粒子或额外投射物。
- 其他模型及结构不符合的替换模型使用通用距离视觉路径，保留原锚点与浓度功能。它们仍可能存在整体放大带来的长度/厚度变化。
- 把视觉修正放在原生 3D 动画更新之后，更新前撤回上帧自己的改动；移除视觉适配器的物理更新钩子。保留其余成长、风暴及实例快照实现。

算法和材质安全边界见 ARCHITECTURE.md。TCSF 仍是用户实测有效的参照；这次改变了原始角度和初始半径的处理约束，没有直接把旧测试的四倍结果当作新版本校准值。

Release DLL 编译通过。两次 0.9.0 数据构建的 ESP、RuntimeForms.h、FormIds.json 一致；与 0.8.0 比较，360 条玩法记录的载荷与标志逐字节不变，仅插件头版本说明改变。六份 PSC/PEX、18 份 NIF、4 份 DDS 与旧包相同；未加入此次检查的游戏投射 NIF。

只读核对了九份原版 NIF 的节点/材质和 Steam 1.7.104.0 的 PE/RTTI/虚表、原生 3D 更新及材质复制/释放流程。外部 Address Library 文件本次未重新核验。未进行真实渲染、游戏 VM、性能或存档测试。

其余功能保持：风暴逐目标独立随机 RemoteCast 1/2/3 次、动态敌我识别与新目标加入、失效停止、原版天气/伤害/抗性；元素狂暴九条独立规则；Soul Tear 基础 10°；Slow Time 玩家豁免；FT Dragon Aspect、英灵、库存模型；动态推力及其他既定龙魂成长。对 0.5.0 的完整保留清单见 docs/verification/feature-coverage-050.json。

## 安装与对照

完整包用于 Steam Skyrim 1.7.104.0 / SKSE64 2.3.1 / 匹配 Address Library。用模组管理器安装，将 Data 作为数据目录，完整替换旧 Ysmir 并启用 Ysmir.esp。源码包不能用作运行包。只启用一套已整合控制器，不与独立 TCSF 同时叠加测试。

优先用三词不卸之力，在相同场景比较零龙魂与 100 龙魂、每魂 5% 的近中远表现，再看火焰/寒霜的三个词阶。观察出生大小、远端覆盖、波纹厚度、烟雾细节和消散。随后确认 Soul Tear 通用路径及风暴等既有功能。

`[TrueCone] NativeWaveGrowth=1` 是新版默认；设为 0 对照同样距离/碰撞条件下的通用根节点路径。`DensityCompensation=0` 只关闭纹理/浓度补偿；`PatchVisuals=0` 关闭锥形视觉补偿而保留距离成长。配置修改后退出并重启游戏。`fVisualTransitionDistance=256` 控制接入距离，旧 fBaseVisualScale/PatchRuntimeCollision 不再生效。

需要诊断时将 `[General] bDebugLogging=1`，日志会记录 native wave 是否启用、层数和 UV 是否获得独立材质；日志位于游戏文档目录的 SKSE/Ysmir.log。画面/命中、接缝、闪烁、残留与帧率仍需用户实测，不把材质包围球当作可见边缘。
