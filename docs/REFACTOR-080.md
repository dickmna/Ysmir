## 现在怎样引雷

1. SKSE 默认每 0.25 秒发现和复查范围内的活敌人。范围仍为 12800×本次范围成长，保留动态敌我识别。新进入的目标独立加入。
2. 每个目标独立等待 3–6 秒后开始第一轮。短脚本按当前风暴词阶调用原版 RemoteCast 1/2/3 次，两次之间各自随机等待 0.12–0.35 秒。
3. 该目标完成后，独立等待下一轮：一词 3–6 秒、二词 0.75–6.75 秒、三词 0.25–5.25 秒。其他目标可以同时处在不同进度；不设置全体完成屏障。
4. 每发前复查目标，实际发射钩子再检查一次。死亡、转友、出范围、重吼或风暴结束会取消后续雷击。室内暂停攻击但持续时间继续，外出后不会集中补发。

保留旧 INI 键名和数值：fPassStaggerMin/Max 现在表示同一目标内的两次雷击间隔，fNoTargetRetry 同时作为动态扫描和暂停重试间隔。实际 Utility.Wait 可能受 VM 负载拖延，不宣称硬实时。

## 保留与精简

- 单次雷击复用原版定位物和 RemoteCast 参数。删除旧 DirectedLaunch 和 C++ 起点、方向、alwaysHit/autoAim 改写；引擎生成和处理法术发射。
- SKSE 只保留目标发现/检查、每目标下一轮时间、必要定位引用、成长接入和失效清理。脚本负责本轮次数及随机等待；没有通用任务框架、批次屏障或第二套后续雷击队列。
- 伤害仍为原版 40/60/80，抗性/吸收交给引擎；保留 bBlameCaster 归责配置。龙魂成长、旧实例倍率、天气、时长、声音、屏幕反馈与既有显示边界修复均保留。仍是一个 Ysmir DLL，无额外视觉 DLL。
- 非风暴部分保留 0.7.0 的纠偏：元素狂暴九条独立规则、重吼不清冷却，Soul Tear 基础 10°，Slow Time 玩家豁免及固定时长，FT 完整机制和模型。已明确删除的投射角度加宽继续删除。
- 连击次数和等待交由原生 Papyrus 栈保存；SKSE v5 仅保存风暴倍率、各目标引用和下轮节奏，兼容读取旧 v3/v4。游戏内完整存读档恢复仍待实测。

本次减少的是自定义发射逻辑。独立目标及引用清理需要少量状态，不把新增的存档/生命周期处理包装成“总行数一定更少”或“所有功能完美”。

## 验证

- DLL Release x64、ESP 数据构建、6 个 Papyrus 脚本全部编译通过。
- 65 项离线场景通过：17 项桥接/碰撞/开关，20 组风暴状态，9 组元素触发，11 组成长/发射钩子，8 组实际编译 PEX 控制流。
- 与 0.7.0 的 360 条玩法记录及标志完全一致；仅 TES4/SNAM 的版本说明改变。未增加/删除记录，RuntimeForms.h 与稳定 ID 不变。
- 0.5.0 的 350 条原有记录 ID、78 个词位数值清单保留；非角度选项和旧 Papyrus API 继续保留。0.7.0 已做的默认风暴伤害纠正保留。
- ESP 和头文件重复生成逐字节相同；最终 DLL 的版本/导出及实际 1.7.104.0 EXE 钩子核验通过。
- 18 个 NIF、4 张 DDS 与原包逐文件哈希一致，包含全部 FT 龙吼库存模型；无 Community Shaders 依赖。
- 完整包：1 DLL、1 ESP、1 INI、6 PEX、18 NIF、4 DDS，另附脚本源码、许可证和说明。两个 ZIP 做 CRC 与逐成员 SHA-256 校验。

这些是实际源码、编译产物和数据的离线验证，未实现完整游戏 VM/物理/伤害系统。仍需实测 RemoteCast 实际命中与抗性归责、雷击画面、天气交接、保存途中连击的恢复，以及多敌人/高龙魂的性能。停止后续施放不会回收已发出的投射物。

## 安装

对应 Steam Skyrim 1.7.104.0、SKSE64 2.3.1 和匹配 Address Library。用 MO2/Vortex 安装 Full.zip，将 Data 设为数据目录并启用 Ysmir.esp；完整替换旧 Ysmir 模组目录。Source.zip 是重编译源码，不是运行模组。

已整合的独立组件及其旧补丁应停用以避免重复运行。0.7.0 用户的配置数值可沿用；更老版本的自定义 30/120 风暴伤害覆盖不会自动改成 40/80。保留升级前存档。

机器可读结果见 Ysmir-0.8.0-验证结果.json，产物哈希见 Ysmir-0.8.0-SHA256.json。
