# 0.9.0 实现与保留边界

## 公共成长

`progression.cpp` 保留 Shout Progression 的龙魂成长目标与配置。`shout_dispatch.cpp` 保留 Ysmir 0.5.0 的玩家私有映射和每次施放倍率：数据加载时建立扁平法术计划，从原始数值计算，施放时只读取一次龙魂。NPC 和玩家通过临时词位替换隔离。

旧投射物、cloak 和延迟子法术必须继续使用自己的施放倍率。因此保留对应实例上下文和暂时应用/恢复数值的作用域；没有换成全局“最后一次施放”倍率。ScriptEffect 仅跟踪六个实际需要 Ysmir 桥接的 MGEF。快照和取消状态合并为同一个上下文；队列只持弱引用和演员句柄，父效果结束、销毁、切换存档或禁用后取消。

Slow Time 和 FT 战斗召唤的普通 Papyrus Cast 不携带 Ysmir 的父效果快照；直接去掉桥接无法保证延迟执行和重吼交错时的 0.5.0 行为。保留两个小型转接脚本、两个推力脚本和一个 native API 声明脚本。推力只调用原生 PushActorAway 一次；零持续时间效果在 Finish 后仍可只读原倍率，不能因此重新排队施法。保留 GetDragonSoulCount。

普通脚本/cloak 快照读档后按加载基线重建，这是既有边界；未增加一套通用存档框架。

## 风暴

原版引雷流程通过空中标记、目标位置标记和 Spell.RemoteCast 施放实际雷击。0.8.0 直接使用这一单次流程；不覆盖原版全局脚本，也不同时运行原版的循环引雷。

storm_call.cpp 沿用原有帧更新，按 fNoTargetRetry（默认 0.25 秒）重新扫描 12800×范围倍率的三维球。只纳入仍存活、3D 已加载且 IsHostileToActor(player) 的目标。新敌人得到自己的初始随机等待，不必等其他敌人的连击结束；同一目标最多有一个正在执行的短脚本。

每个目标使用原版 0xB79FF 定位物的两个实例，分别作为空中来源和瞄准点，存活期间复用。开始一轮后，YsmirStormScript.Burst 按词阶执行 1/2/3 次 RemoteCast，相邻两次分别调用 Utility.RandomFloat 和 Utility.Wait。每个目标独立计时，默认间隔 0.12–0.35 秒；完成后独立抽取既有的下一轮间隔。没有全局批次完成屏障或预先排好的后两发队列。

StormReady 每次检查有效风暴、目标敌友/存活/范围状态，按当前目标位置更新两个标记，并准备本次风暴的成长值。返回 -1 终止、0 暂停、1 允许 RemoteCast。StormFinished 只结束该目标的一轮并确定下一轮时间。两个入口都使用普通 VM native 绑定，不开放 tasklet 调用。

既有 Projectile::Launch 钩子对私有雷击核对来源标记、当前词阶、瞄准标记和目标状态，拒绝失效请求，并接入既有实例成长与视觉跟踪。删除旧 DirectedLaunch：不再改写 LaunchData 的起点、方向、alwaysHit、autoAim、power、scale 或 castingSource。空中起点和目标由标记交给 RemoteCast；归责仍由 bBlameCaster 选择目标或玩家并传给引擎。

官方三个雷击 Spell 的私有副本、40/60/80 基础伤害、Health/DualValueModifier/ResistShock 和整套龙魂倍率保留。已发射雷击保留自身快照；停止是取消后续施放，不会回收已经发射的投射物。是否实际命中、造成多少伤害仍由引擎决定。

持续时间仍由私有 StormDuration ActiveEffect 管理。室内暂停搜索和攻击，效果时长继续；短脚本暂不消耗剩余次数。返回室外逐次继续等待，不集中补发。原版 magicSetWeatherScript 保持天气例外表、重吼延长与结束释放；雷击声音、屏幕反馈及现有显示边界修复保留，仍只有一个 Ysmir DLL。

目标失效、风暴结束或重吼时移除本轮目标并释放定位标记。读档之前只丢弃旧世界的句柄，不删除即将被替换的世界对象。STRM v5 保留既有固定头以读取 v3/v4，另外每个目标使用一个 20 字节 TRGT 记录保存引用 ID、下一轮剩余等待和是否正在连击。连续次数与 Wait 的恢复交由 Papyrus 自身保存的执行栈；没有复制 VM 或加入通用存档框架。缺失目标和禁用后的恢复会清理仍存在的标记。真实存档与 VM 联合恢复仍需游戏内验证。

## 元素狂暴

使用原数据的三个词阶和三种元素。每条匹配的 hitframe 规则独立投 50% 概率、独立 2 秒冷却，共九个计时器；按 DAC 的顺序先投概率、检查冷却、先更新时间再施法。多个词阶并存时都评估，重吼不清冷却。冷却采用包含菜单时间的墙钟；暂停时不触发攻击。每个词阶保留自己的成长快照。读档/新游戏重建瞬时状态；不引入额外跨存档 DAC 状态。

## 锥形和视觉

保留记录与引擎给出的原始锥角和初始半径，Soul Tear 的 ConeSpread 仍为上游 10°。删除 initialCollisionSphereRadius 写入、Geometry 半径缓存和 Cone Update 前的碰撞处理。原生更新继续负责 R(d)=r+d*t 的碰撞扩张、bhk/Havok 形状与单位转换。这里的 R 是移动碰撞球的半径，不是一个静止圆锥的精确命中边界。

沿用现有视觉更新钩子，只读原生 distanceMoved、initialCollisionSphereRadius 和 coneAngleTangent，不猜测记录角度的半角/全角。K 为本次施放的距离倍率，默认 1+0.05S，继续同时作用于速度和射程。视觉使用：

```text
Q(d) = (r + d*t) / (r + (d/K)*t)
u = clamp(d/L, 0, 1)
w = u*u*(3 - 2*u)
V(d) = 1 + (C*Q(d) - 1)*w
```

C 为基础视觉参考，fBaseVisualScale 默认 4；L 为实际移动的过渡距离，fVisualTransitionDistance 默认 256 引擎单位，两项至少取 1。不是按时间、最大射程或帧数计时。d=0 时严格为 1；Q 的分母为零时取 1，非有限/无效运行数据返回原始尺寸。r=0、t>0 时平滑权重仍保证出生连续。每帧从原始/引擎动画更新后的基线计算，不累乘上一次结果；每个投射物沿用自己的施放快照。

零龙魂时 Q=1，默认在 d=0/128/256 时依次为 1/2.5/4 倍。龙魂距离成长使目标 C*Q(d) 随传播继续变化，4 倍不是龙魂上限。smoothstep 消除过渡权重在两端的斜率突变；有距离成长时，过渡结束后目标自身仍可继续平滑增长。d/K 假设原模型传播进度与成长前对应，因此这是几何依据的视觉近似，不是逐模型边缘拟合。

模型空间锚点复用原实现：T'=C_parent-R*(scale*anchor)。它固定投射物参考点对应的模型位置，不额外加 Z、不单独放大子节点、不替换 NIF。模型上下边缘仍会随整体放大自然扩张；也不保证整个喷射期间嘴边粒子始终保持原尺寸。

浓度保留原 Alpha/加法材质公式和排除列表，改为以当前平滑后的 V 计算 1+(fTrueConeDensityAt4x-1)*(V-1)/3；出生补偿为 1，默认 V=4 时为 2.2。共享材质仍共用一个基线，材质替换和清理恢复保留；共享材质只能同时显示一组浓度。

TrueCone.Enabled、PatchVisuals 和 DragonSouls.bScaleVFX 任一关闭，均不应用锥形尺寸/浓度补偿。PatchRuntimeCollision 已删除并忽略旧键；非锥形碰撞仍使用 bScaleCollisionRadius/fCollisionRadiusPerSoul。fVFXPerSoul 继续控制非锥形视觉，锥形改由距离倍率和上述几何补偿驱动，不再叠乘它。非锥形/风暴的原视觉倍率、显示边界与 AlwaysDraw 路径保留。

## 数据与状态

五个上游插件由 SHA-256 锁定。0.5.0 的 350 条记录与稳定 ID 全部保留；新增 10 条风暴记录。与 0.6.0 的二进制比较中，348 条旧记录载荷完全相同，仅 Soul Tear 和风暴投射物两条变更。78 个根词位的数值清单不变；风暴伤害默认值在 INI 和新子法术中纠正。

FormIds 保留旧顺序和旧 ID，生成器输出更新后的分配表。成本减免 perk 直接引用官方，不额外私有化。没有增加任务、全局变量、词墙、定制天气记录、通用事件框架或新外部运行依赖。
