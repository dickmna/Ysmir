# 0.5.0 几何与实例状态

## 几何

设距离倍率为 `Md`、碰撞倍率为 `Mc`、视觉倍率为 `Mv`。默认全部为 `1 + 0.05S`。从未修改的投射物初始化数据捕获原始半径 `r0` 和切线 `t0`，按运行时的半角/全角约定得到至少 15° 的基础切线 `t1`。

对于已移动距离 `d`，原始动画进度对应距离为 `u=d/Md`。目标碰撞截面为 `Mc*(r0+u*t1)`，因此初始化半径为 `Mc*r0`，运行时切线为 `t1*Mc/Md`。视觉根倍率为 `Mv*(r0+u*t1)/(r0+u*t0)`；分母为零时使用基础视觉倍率。

这依赖讨论中的前提：原始 VFX 与原始碰撞包络匹配，且 VFX 随动画进度扩展。这里没有测量每种 NIF 动画的可见边缘；粒子透明度、动画控制器、外部 mesh replacer 可能使实际观感偏离该前提。不同方向的独立拉伸也不是 NiTransform 的均匀缩放所能完全表达的。

设 `C` 是转换到父节点空间的投射物中心，原始根变换为 `T0,R0,S0`。首次绑定 3D 时捕获模型空间锚点 `c0 = inverse(R0)*(C-T0)/S0`。缩放后根位置为 `T = C - R*(S*c0)`。这个式子直接保证 `T+R*(S*c0)=C`；没有单独的 Z 经验项、动态包围盒中心采样或局部核心节点二次放大。

浓度是独立外观补偿：Alpha 使用 `1-(1-alpha)^gain`，加法材质提升颜色/发光强度，保留原有视觉强度安全界限。它不改变碰撞和伤害。

## 生命周期

数据加载阶段生成扁平法术计划，并确定乘幅度、cloak 半径、Slow Time 反比和固定持续时间规则。每次施放只捕获一次龙魂。Projectile::Launch 保存出生快照；ScriptEffect/CloakEffect 保存 ActiveEffect 实例快照。Papyrus 传递 Self，复制快照后通过主线程队列施放关联子法术；读档代号会取消旧队列工作。

投射物物理初始化、更新、命中和 cloak 更新以自身快照临时应用所需图；数值一致时不分配回退缓存或回写记录，退出时恢复进入前的确切记录值。图可有共享依赖，不能用另一个“最后施放”的猜测值恢复。法术级快照只为尚未创建的延迟效果及读档恢复提供起点，已登记实例保持自己的快照；没有用全局最近一次施放给缺失实例兜底。

每个有效投射物句柄保存一份视觉状态，锥形与其他投射物共用它。3D 根变化时才发现节点和材质；帧更新只访问已绑定项。共享材质通过弱引用表去重，活跃绑定持有 shader，失效绑定重新建立；投射物失效后回收状态及材质引用。没有永久裸地址回退或 4096 个材质硬截断。

读档会清理暂存指针，重新建立当前加载的数值基线；恢复的 ScriptEffect/CloakEffect 在更新时登记。该版本没有为这些瞬时缓存新建存档序列化格式，不能承诺跨读档仍保留保存前的龙魂快照。风暴继续使用已有序列化格式保存自己的运行状态。

## 构建

SourceRules 明确列出机制来源，FormIds 仅固定 ID。直接从五个原始上游文件和官方获胜记录生成私有图，再进行可达性剪枝与 MagicShout 分类。普通数值、FT/SCSO 例外与 Battle Fury 排除保持约定。
