# 0.7.0 实现与保留边界

## 公共成长

`progression.cpp` 保留 Shout Progression 的龙魂成长目标与配置。`shout_dispatch.cpp` 保留 Ysmir 0.5.0 的玩家私有映射和每次施放倍率：数据加载时建立扁平法术计划，从原始数值计算，施放时只读取一次龙魂。NPC 和玩家通过临时词位替换隔离。

旧投射物、cloak 和延迟子法术必须继续使用自己的施放倍率。因此保留对应实例上下文和暂时应用/恢复数值的作用域；没有换成全局“最后一次施放”倍率。ScriptEffect 仅跟踪六个实际需要 Ysmir 桥接的 MGEF。快照和取消状态合并为同一个上下文；队列只持弱引用和演员句柄，父效果结束、销毁、切换存档或禁用后取消。

Slow Time 和 FT 战斗召唤的普通 Papyrus Cast 不携带 Ysmir 的父效果快照；直接去掉桥接无法保证延迟执行和重吼交错时的 0.5.0 行为。保留两个小型转接脚本、两个推力脚本和一个 native API 声明脚本。推力只调用原生 PushActorAway 一次；零持续时间效果在 Finish 后仍可只读原倍率，不能因此重新排队施法。保留 GetDragonSoulCount。

普通脚本/cloak 快照读档后按加载基线重建，这是既有边界；未增加一套通用存档框架。

## 风暴

原版根范围效果只在施放时覆盖目标，原版引雷脚本围绕已有目标 RemoteCast；无 Spell 的 CallStormHazard01 不负责动态寻敌。SCSO Pure SKSE 3.0.1 Beta 也只给原雷击补击。因此，对后来入场的所有敌人重新筛选仍需 Ysmir 的调度器。

新的 storm_call.cpp 保留 12800×范围倍率的三维球形搜索、IsHostileToActor、每批重新获取全部有效目标、发射前复查句柄，以及一/二/三词对应一/二/三批。随机错峰 0.12–0.35 秒；长帧最多补一批，下一批重新保持间隔。保留既定起始等待、轮次等待、无目标重试和配置。

持续时间由私有 StormDuration ActiveEffect 管理。室内暂停攻击节奏，效果时间继续，返回室外不积累补击。天气使用独立的原版 magicSetWeatherScript 效果：保留 Update.esm 的天气例外列表，待合法室外再施放；重吼延长现有天气效果，结束时让原脚本释放覆盖。没有直接操作 Sky 的天气会话。

雷击使用官方三个 Spell 的私有副本，基础 40/60/80，DualValueModifier、Health 和 ResistShock 保持。通过玩家的 instant MagicCaster 施放，并将 bBlameCaster 对应的演员交给引擎归责参数。已有 Projectile::Launch 钩子在这个短作用域内只设置空中起点、方向和目标；Spell、power、施法来源和 actor cause 由引擎生成。这样不会把受击者同时当作投射物发射来源，也不手动扣血或手写抗性公式。

主雷击与额外批次都走同一实际法术路径。官方投射物数值、雷击高度/散布、声音、屏幕反馈及 SCSO 显示边界修复保留。目标可能受游戏的抗性、吸收或命中逻辑影响；“所有敌人”指每批向每个合格目标发起雷击，不表示绕过引擎防护。

仅风暴保留小型 SKSE STRM 序列化，存倍率和剩余节奏。v4 读取原 v3 固定记录；0.5/0.6 旧风暴没有引擎计时效果时，用剩余时间重建该效果。没有第二套独立的持续时间倒计时，也不序列化自建天气所有权。

## 元素狂暴

使用原数据的三个词阶和三种元素。每条匹配的 hitframe 规则独立投 50% 概率、独立 2 秒冷却，共九个计时器；按 DAC 的顺序先投概率、检查冷却、先更新时间再施法。多个词阶并存时都评估，重吼不清冷却。冷却采用包含菜单时间的墙钟；暂停时不触发攻击。每个词阶保留自己的成长快照。读档/新游戏重建瞬时状态；不引入额外跨存档 DAC 状态。

## 锥形和视觉

只移除角度加宽、最低角度和切线/视觉角度补偿。Soul Tear 的数据 ConeSpread 为上游 10°。True Cone 的 Enabled、PatchRuntimeCollision、PatchVisuals 三个独立控制保留；DistanceVisualScale 属于已删除的角度补偿。

原始半径从 PROJ 读取，适配器仅写 initialCollisionSphereRadius。引擎计算锥体扩展、Havok 实际形状和单位转换；不直接把 bhk 包装对象当作 hkpSphereShape 写入。距离控制速度/射程，碰撞控制初始半径，视觉控制根节点均匀缩放。

模型空间中心锚点保证缩放围绕原中心，无额外 Z 抬高或子节点二次缩放。浓度独立处理普通 Alpha 和加法材质；共享材质使用共同基线，逐几何节点检查材质替换。共享材质只能同时显示一组浓度，这一边界不影响各实例的数值。

## 数据与状态

五个上游插件由 SHA-256 锁定。0.5.0 的 350 条记录与稳定 ID 全部保留；新增 10 条风暴记录。与 0.6.0 的二进制比较中，348 条旧记录载荷完全相同，仅 Soul Tear 和风暴投射物两条变更。78 个根词位的数值清单不变；风暴伤害默认值在 INI 和新子法术中纠正。

FormIds 保留旧顺序和旧 ID，生成器输出更新后的分配表。成本减免 perk 直接引用官方，不额外私有化。没有增加任务、全局变量、词墙、定制天气记录、通用事件框架或新外部运行依赖。
