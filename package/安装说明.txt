Ysmir 0.9.1 — 整体缩放游戏测试包

运行要求：Steam Skyrim 1.7.104.0、SKSE64 2.3.1、匹配 Address Library、
官方 masters 和 Visual C++ x64 Runtime。其他运行时未验证。

用 MO2/Vortex 安装 ZIP，把 Data 设为数据目录并启用 Ysmir.esp。
完整替换旧 Ysmir 模组目录；保留升级前存档。Source.zip 不是运行包。
停用已整合的 Shout Progression、FT、True Cone、DUF、SCSO、93681、
62686、49359 对应控制器及补丁，避免重复执行；其他未整合组件按需保留。
独立 TCSF 请用单独配置作参照，不与本版叠加评价新效果。

本版删除分层、模型特例和专用 UV 处理，所有锥形特效统一整体缩放。
保留原版出生大小与锚点；倍率随龙魂距离成长平滑增加，无固定四倍。
角度和初始碰撞半径不改，不抬高、不换投射 NIF。
原有浓度补偿和风暴、元素狂暴、Soul Tear、Slow Time、FT、推力、成长保留。

测试顺序：
1. 用三词不卸之力比较零龙魂和 100 龙魂（每魂 5%）。
2. 观察出生、近处、中段、远端覆盖，波面/烟雾/拖尾的比例衔接及高度。
3. 检查火焰/寒霜各词阶、Soul Tear，以及风暴/元素狂暴/Slow Time。
4. [TrueCone] DensityCompensation=0 可单独关闭浓度补偿作对照；默认 1。
5. PatchVisuals=0 可关闭锥形视觉补偿，龙魂距离成长继续保留。
所有 INI 修改后退出并重启游戏；建议安装本版配置后迁移自定义数值。

fVisualTransitionDistance=256 控制平滑接入距离。
NativeWaveGrowth 已删除并忽略旧键；不再存在可切换的分层路径。
旧 PatchRuntimeCollision、角度键和 fBaseVisualScale 也继续忽略。
fVFXPerSoul 只控制非锥形视觉。需要诊断时设置 General.bDebugLogging=1，
日志 SKSE/Ysmir.log 会记录 uniform root scale、浓度目标数和距离倍率。

包含 1 DLL、1 ESP、1 INI、6 PEX、18 NIF、4 DDS；保留 FT 17 个库存模型。
没有新增或替换投射 NIF，无 Community Shaders 依赖。
Release 构建和 96 项离线检查通过；360 条玩法记录、六份脚本和原资产
与 0.9.0 核对一致。尚未进行真实游戏画面、命中、帧率和存档联合测试。

回退：恢复 0.9.0 完整包及升级前存档；GitHub v0.9.0 / backup/ysmir-0.9.0
对应 733c0c8。本次没有自动部署到游戏或更改加载顺序。
