Ysmir 0.8.0 — 完整本地安装包

对应 Steam Skyrim 1.7.104.0、SKSE64 2.3.1、匹配 Address Library、
官方 masters 和 Visual C++ x64 Runtime。其他运行时未验证。

用 MO2/Vortex 安装本 ZIP，把 Data 设为数据目录并启用 Ysmir.esp；
完整替换旧 Ysmir 模组目录。Source.zip 用于重编译，不能当运行模组安装。
0.7.0 配置数值可继续用；更老 INI 中的 30/120 风暴伤害覆盖不会自动纠正。
停用已整合的独立 Shout Progression、FT、True Cone、DUF、SCSO、
93681、62686、49359 相应组件及旧补丁，避免重复运行。

风暴现为每目标独立随机错峰：SKSE 动态识别敌人，短脚本 RemoteCast
按词阶施放 1/2/3 次。新敌人加入，失效目标和结束风暴停止后续施放。
保留龙魂成长、归责设置、原版天气与时长，以及所有既有非角度功能。
含 1 DLL、1 ESP、1 INI、6 PEX、18 NIF、4 DDS，附源码/许可证/说明。
FT 全部 17 个库存模型保留，无 Community Shaders 依赖。

DLL、数据与六个脚本编译通过；65 项离线场景及记录/PE/包完整性检查通过。
未做游戏实测，实际命中、画面、存读档联合恢复与性能仍待验证。
详见 docs/REFACTOR-080.md 和 docs/KNOWN_ISSUES.md。

重构前源码已备份至 GitHub v0.7.0，提交 5bcfaaa；
旧完整包保留。回退请使用旧包和升级前存档。
